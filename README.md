# Placement Tracker

A MERN stack-based web application to manage placement opportunities, track applications, and monitor student progress.

##  Features
- User Authentication (Login/Register)
- Add & Manage Job Opportunities
- Track Application Status
- Dashboard for student progress

##  Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB

## ⚙️ Installation

```bash
git clone https://github.com/kavya-Nune/placement-tracker.git
cd placement-tracker
npm install
Backend:
cd backend
npm start
Frontend:
cd frontend
npm run dev
